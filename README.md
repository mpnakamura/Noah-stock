# AI PM Assistant

PM業務を支援する対話型マインドマップツール

## プロダクト概要

プロダクトマネージャーの「引き算の意思決定」を支援する対話型マインドマップツールです。
要件を入力すると、AIが「やること/やらないこと」「リスク」「トレードオフ」の観点でマインドマップを生成し、対話を通じてブラッシュアップできます。

## 主な機能

### Phase 1: MVP ✅
- 📝 **要件入力**: 自由記述で要件やアイデアを入力
- 🤖 **AI自動生成**: 入力内容から階層的なマインドマップを自動生成
- 🎨 **インタラクティブ可視化**: ズーム、パン、ノードの展開/折りたたみ
- 💾 **エクスポート**: JSON、PNG形式での保存

### Phase 2: Enhancement ✅
- ✏️ **手動編集**: ノードの追加・削除・ラベル編集が可能
- 📚 **テンプレート**: PMスキル、プロジェクト計画、技術スタックなど4種類のテンプレート
- 💾 **履歴管理**: LocalStorageで自動保存、履歴一覧から再読み込み可能
- 🔄 **リアルタイム編集**: 編集モードで即座に変更を反映

### Phase 2.5: PM支援特化 ✅
- 🎯 **PM特化型プロンプト**: 「やること/やらないこと」「リスク」「トレードオフ」を自動生成
- 💬 **対話型チャット**: AIと対話しながらマインドマップをブラッシュアップ
- 📋 **PMテンプレート**: 新機能開発、MVP計画、リスク分析など実践的なテンプレート
- ✂️ **スコープ絞り込み支援**: 「引き算の意思決定」をサポート
- 📱 **改善されたUI**: サイドバー + フローティングチャットボット形式

## 技術スタック

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Visualization**: React Flow
- **AI**: Anthropic Claude API

## 使い方

### AI生成モード
1. アプリケーションを起動
2. 要件やアイデアをテキストエリアに入力
3. 「マインドマップを生成」ボタンをクリック
4. AIが自動生成したマインドマップを確認

### テンプレートモード
1. 「テンプレートから始める」セクションから好きなテンプレートを選択
2. 選択したテンプレートがマインドマップとして表示される

### 編集モード
1. マインドマップ上部の「編集」ボタンをクリック
2. ノードをダブルクリックでラベル編集
3. ノードを右クリックで「子ノード追加」「削除」メニュー表示
4. 編集完了後、「履歴に保存」ボタンで保存

### 履歴から読み込み
1. 「最近の履歴」セクションから過去のマインドマップを選択
2. クリックで再読み込み、ゴミ箱アイコンで削除

### サイドバー
1. 画面左上のボタンでサイドバーを開閉
2. 入力フォーム、テンプレート、履歴が含まれる
3. 閉じるとマインドマップが全画面表示

### AIチャット（フローティング）💬
1. 右下の青いチャットボタンをクリック
2. チャットウィンドウがポップアップ
3. クイックアクション:
   - 「詳細化して」- 指定ノードを詳しく
   - 「リスクを分析して」- リスクと対策を提案
   - 「何が足りない？」- 不足観点を指摘
   - 「スコープを絞って」- やらないことを提案
4. 自由な質問も可能（例：「〇〇を詳しく」「〇〇のリスクは？」）
5. チャットを閉じてもマインドマップは広々表示

### エクスポート
- JSON: データ構造をそのまま保存
- PNG: 画像として保存
